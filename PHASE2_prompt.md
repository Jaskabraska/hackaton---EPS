## 1. Orientation

Grid Pulse is a decision-support dashboard for an electricity transmission-grid **dispatcher**,
built on the IEEE-118 ČEPS dataset (118 buses, 3 regions r1/r2/r3, 186 branches, 321 generators,
8760 hourly solved load-flow snapshots, day-ahead MW forecasts, fuel prices).

- Backend: Python + FastAPI + **pandapower** in `backend/app/**`
  (`grid/{loader,state,contingency,topology}.py`, `analysis/{alerts,economics,forecasts,analogues,
  playback,playbook,day_bundle}.py`, `llm/{orchestrator,provider,tools,glossary.json}.py`,
  `config.py`, `main.py`, `schemas.py`, tests in `backend/tests/`).
- Frontend: Next.js + TypeScript + Tailwind in `frontend/**`
  (`components/{GridMap,AlertsPanel,AiSummary,KpiTiles,NodeInspector,ChatBox}.tsx`,
  `lib/{api,types}.ts`, `app/page.tsx`).
- **Read first:** `SPEC_backend_demo.md`, `Grid_Pulse_MVP_plan.md`, and `grid_pulse_city_demo.html`
  (the reference for the source-type node icons). Then inspect the code above.
- Coding rules: TypeScript **no semicolons**, use **fetch**, **date-fns**, **British spelling**,
  **sentence case** in UI text.
